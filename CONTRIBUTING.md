# Contributing to IT AI Learning Hub

## ✅ Submission Format

Please use this format when adding resources:

### Title:
### Category: (Blog / Course / Tool / Usecases)
### Level: (Beginner / Intermediate / Advanced)
### Link:
### Description:
Short summary (2-3 lines)

---

## 📂 Where to Add
- Blogs → /blogs
- Courses → /courses
- Tools → /tools
- Usecases → /usecases

---

## ⚠️ Rules
- No duplicate resources
- Verify links before submitting
- Keep descriptions concise
- Use clear file naming
